    后端八股复习指南：博客文章索引

    2026-08-17 | in DailyDev
    面试 八股 后端 复习

    写在前面

    网络

    网络是后端八股的地基，面试必问。TCP 握手挥手、IO 模型、HTTP 协议，这几篇覆盖了核心考点。

    • TCP的三次握手与四次挥手 — 含面试高频考点，SYN/FIN 状态机、TIME_WAIT 原因与调优
    • 搞懂 BIO 与 AIO — select/poll/epoll 对比，高并发 IO 模型演进，面试重点
    • WebSocket 面试详解 — 长连接原理、心跳机制、粘性会话、与 HTTP 的区别
    • 《HTTP 权威指南》记录 — HTTP 协议细节、状态码、缓存控制、内容协商

    数据库

    MySQL 是后端面试的重中之重，索引、锁、事务隔离级别几乎必考。PostgreSQL 和 MongoDB 属于加分项。

    • MySQL 面试八股（一）：架构、存储引擎与索引 — 字段类型速记、SQL 执行流程、InnoDB/MyISAM、B+ 索引全解（覆盖索引/最左前缀/索引下推）
    • MySQL 面试八股（二）：事务、锁与日志 — 事务隔离级别、三类行锁、redo/binlog/undo、MVCC 可见性
    • MySQL 面试八股（三）：MVCC 与隔离级别深挖 — Read View 可见性五步算法、RC 与 RR 差异逐例推演、Next-Key Lock 防幻读
    • MySQL 面试八股（四）：三类日志与两阶段提交 — redo 的 WAL 与刷盘策略、binlog 三种格式、两阶段提交与崩溃恢复
    • SQL 优化实战（一）：EXPLAIN 读懂执行计划 — type/key/Extra 逐列拆解、覆盖索引与 filesort 实战案例
    • SQL 优化实战（二）：慢 SQL 定位与索引优化 — 慢查询日志定位、索引设计、七种索引失效场景
    • MySQL 高频手写 SQL 练习 — 分组 TopN、连续登录、行转列、留存率、中位数等八道真题题解
    • Mysql 必知必会读书笔记 — SQL 基础、增删改查、连接查询、子查询
    • 《高性能 MySQL》记录 — 索引原理、查询优化、锁机制、事务隔离级别
    • 《PostgreSQL 指南》记录 — PG 特性、与 MySQL 的差异、适用场景

    缓存与分布式

    Redis 和分布式锁是面试高频中的高频，缓存穿透/击穿/雪崩三连问几乎逃不掉。

    • Redis 面试八股（一）：数据类型与底层结构 — SDS 底层、跳表选型、线程模型、过期删除与内存淘汰
    • Redis 面试八股（二）：持久化、缓存与集群 — RDB/AOF/混合持久化、缓存三兄弟、bigkey/hotkey、Sentinel 与 Cluster
    • 《高效使用 Redis》记录 — Redis 数据结构、持久化、过期策略
    • 《Redis 深度历险》记录 — Redis 进阶原理、集群、分布式锁实现
    • 面试漫谈：缓存的三大场景与分布式锁 — 缓存穿透/击穿/雪崩 + 分布式锁方案对比

    消息队列

    消息队列考察异步解耦、削峰填谷的理解。Kafka 和 RabbitMQ 是两大主流。

    • 消息队列面试八股（一）：Kafka — 消息模型、多副本与 ISR、消息不丢失四件套、重复消费与重试
    • 消息队列面试八股（二）：RabbitMQ — 交换器四型、死信与延迟队列、可靠性三段、高可用模式
    • 消息队列面试八股（三）：常见问题与通用解法总纲 — 跨 MQ 通用考点：三段式不丢失、幂等四法、key 分流保序、积压处置、延迟与死信、五性总纲
    • Kafka 简单入门 — 核心概念、分区与副本、Go 实战、面试高频考点
    • 《Kafka 权威指南》记录 — Kafka 深入原理、消费者组、精确一次语义
    • 《深入 RabbitMQ》记录 — RabbitMQ 架构、消息确认、高可用队列

    Go 语言

    Go 是主力语言，并发模型和标准库是面试考察重点。sync 包的底层原理、pprof 性能分析，都是展示技术深度的好素材。

    • Go 面试八股（一）：语言特质与核心数据结构 — 面向对象、make/new、slice 扩容、map 底层、接口
    • Go 面试八股（二）：并发模型与内存管理 — GMP 调度、channel、锁、GC 三色标记、逃逸分析
    • sync 包详解 — Mutex/RWMutex/Map/Once/Pool，面试要点逐条标注
    • pprof 指南 — CPU/内存/Goroutine 泄漏/锁竞争分析
    • 《深入理解设计模式》记录 — 常用设计模式、Go 实现、面试场景
    • 《Go 微服务实战》记录 — 微服务拆分、服务发现、熔断降级
    • gRPC 与云原生应用开发 — RPC 框架、Protobuf、流式通信

    Python 语言

    Python 面试既会问对象模型、容器和函数语义，也常顺着并发模型与内存管理追问。两篇按语言机制到运行时选型排列，适合在技术面前连读复习。

    • Python 面试八股（一）：对象模型、核心容器与函数机制 — 名称绑定、可变性、浅深拷贝、list/dict/set、作用域闭包、生成器与 MRO
    • Python 面试八股（二）：并发、内存管理与工程实践 — GIL 边界、线程/协程/进程选型、同步、引用计数与循环 GC、资源治理

    中间件与工程化

    配置中心、任务调度、容器编排，这些是工程能力的体现，也是简历上的亮点。

    • Apollo 简单入门 — 配置中心原理、灰度发布、动态配置
    • XXL-JOB 简单入门 — 分布式任务调度、执行器架构、面试高频考点
    • 《Kubernetes 编程》记录 — K8s 核心概念、Pod 调度、Service 网络
    • 《Kubernetes 微服务实战》记录 — K8s 上的微服务部署、Helm、Ingress

    分布式理论

    系统设计题的底层逻辑。CAP、一致性协议、分布式事务，理论功底在这里体现。

    • 《数据密集型系统设计》记录 — CAP/BASE、数据分片、复制、一致性
    • 《深入理解分布式共识算法》记录 — Paxos/Raft/ZAB 对比、选主与日志复制

    实习与项目

    面试官深挖简历项目的比例很高，每个项目背后都有一组可展开的技术考点。这套系列按实习与个人项目为背景成文，讲的都是项目真正解决过的工程问题，适合面试前通读建立「项目叙事」的完整逻辑。

    • 实习项目·风控变量系统：从 Pipeline 到 DAG 的调度重构 — 拓扑排序、轮次并行、goroutine 池、并发安全三坑、性能验证
    • 实习项目·DewuClaw：多 Agent 工具调度与协作工程 — 软隔离工作区、Skill Hub 语义匹配、两段式下发、在线反馈修正
    • 实习项目·工业组态 HMI：协议适配与时序数据 — 适配器模式、Modbus TCP/OPC UA、时序库选型、预降采样
    • 项目·电网设备故障辅助诊断系统：多 Agent 运行时内核与可观测 — 消息信封、五态状态机、SQLite 单写者、Auditor 确定性审核、MCP 工具服务器、KV Cache 成本优化

    推荐复习路线

    如果时间紧，按这个顺序过一遍核心篇目：

    第一轮（4天，系统系列优先）：Go 八股两篇、Python 八股两篇、MySQL 八股两篇、Redis 八股两篇、消息队列八股两篇

    （系统系列覆盖了后端面试主干，建议优先通读；若时间仍紧，可从中挑薄弱项）

    第二轮（2天）：TCP 三次握手、高性能 MySQL、缓存三大场景、Kafka 入门

    第三轮（2天）：sync 包详解、epoll 与 BIO、Redis 深度历险、分布式共识算法

    第四轮（2天）：设计模式、xxl-job/apollo、WebSocket、微服务实战

    每篇都有面试高频考点标注，重点看标注部分即可。祝各位面试顺利。
