## 写在前面

博客写了不少东西，但零散分布在各个分类里。趁秋招季，把后端八股相关的文章按主题整理一份索引，方便自己复习时快速定位，也给同路人一个参考。

## 网络

网络是后端八股的地基，面试必问。TCP 握手挥手、IO 模型、HTTP 协议，这几篇覆盖了核心考点。

- [TCP的三次握手与四次挥手](/posts/DailyDev/TCP的三次握手与四次挥手/) — 含面试高频考点，SYN/FIN 状态机、TIME_WAIT 原因与调优
- [搞懂 BIO 与 AIO](/posts/DailyDev/搞懂BIO与AIO/) — select/poll/epoll 对比，高并发 IO 模型演进，面试重点
- [WebSocket 面试详解](/posts/DailyDev/WebSocket面试详解/) — 长连接原理、心跳机制、粘性会话、与 HTTP 的区别
- [《HTTP 权威指南》记录](/posts/DailyDev/《HTTP权威指南》记录/) — HTTP 协议细节、状态码、缓存控制、内容协商

## 数据库

- [Mysql 必知必会读书笔记](/posts/DailyDev/Mysql必知必会读书笔记/) — SQL 基础、增删改查、连接查询、子查询
- [《高性能 MySQL》记录](/posts/DailyDev/《高性能MySQL》记录/) — 索引原理、查询优化、锁机制、事务隔离级别
- [《PostgreSQL 指南》记录](/posts/DailyDev/《PostgreSQL指南》记录/) — PG 特性、与 MySQL 的差异、适用场景

## 推荐复习路线

如果时间紧，按这个顺序过一遍核心篇目：

**第一轮（3天）**：TCP 三次握手 → 高性能 MySQL → 缓存三大场景 → Kafka 入门

**第二轮（2天）**：sync 包详解 → epoll 与 BIO → Redis 深度历险 → 分布式共识算法

**第三轮（2天）**：设计模式 → xxl-job/apollo → WebSocket → 微服务实战

每篇都有面试高频考点标注，重点看标注部分即可。祝各位面试顺利。
